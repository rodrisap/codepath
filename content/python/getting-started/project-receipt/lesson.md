## Brief

Ana López stayed **2 nights** in **room 7 (Double)** at **650 MXN per night**, and had breakfast twice at **120 MXN** each. Print her receipt.

You'll use everything from this module: `print`, text vs numbers, commas, and letting Python do the maths.

One new trick: text can be repeated with `*`.

```python
print("=" * 30)
```

This prints 30 `=` signs in a row, which is handy for separator lines.

**Rule for this project:** never type a result you could calculate. Write `2 * 650`, not `1300`. If the rate changes, the receipt should only need one number changed.
